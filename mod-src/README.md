# BelTranslate smoke mod

Install path (already linked into game):
`Mods/Tweaks/BelTranslate/`

Enable in game: main menu → Модификации / Mods → enable **Belarusian**.

Working test labels:

- Main menu images: **НОВАЯ ГУЛЬНЯ**, **ЗАГРУЗІЦЬ**, **ВЫЙСЬЦІ**
- Pause menu text: **Працягнуць**, **Захаваць**, **Налады**, **Даведка**, **Выхад**

Rebuild from project root:

```bash
.venv/bin/python build_test_mod.py
```
